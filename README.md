# 灵思剪辑 Lite · v0.4.0

本地运行的轻量视频编辑器。导入一条视频，完成片段剪辑、画布裁切、音乐混音、手动字幕、图文图层和 20 款精选动效，再导出无水印 MP4。

## 使用

下载发行包、解压到独立文件夹，安装 Python 3.11+，双击 **启动灵思剪辑.cmd**。浏览器打开 http://127.0.0.1:5031 。仅支持桌面 Chrome / Edge，建议窗口宽度 1100px 以上。

1. 导入 MP4 / MOV / WebM，或点击「打开人物演示」。具体编码需浏览器支持，优先使用 H.264 + AAC 的 MP4。
2. 剪辑：在播放头处分割，删除、复制和排序片段；拖动片段两端裁切，单独设置 0.25×～4× 速度、原声音量和静音。
3. 画布：提供原比例、9:16、16:9、1:1；完整显示或铺满裁切，可缩放、移动、居中、重置并显示安全区。
4. 音乐：导入 MP3 / WAV / M4A，调整开始、结束、裁切起点、音量、循环和淡入淡出；导出时与各视频片段原声混合。
5. 字幕：手动输入或导入 SRT，统一样式、字号、位置、描边和底色；支持查找替换、整体偏移、按字数拆分与合并相邻字幕。
6. 图文：添加主标题、副标题、引语卡片和本地图片 / Logo；设置时间范围、位置、大小、旋转、透明度、圆角、层级、锁定、隐藏与复制。
7. 动效：提供商业版体验清单中的 20 款组件，支持分类、搜索和动态预览。旧 4 款动效继续兼容已保存工程。
8. 点击「保存工程」保留视频、音乐和编辑内容；`.linsi` 工程包包含全部本地素材，可跨浏览器恢复为新副本。点击「导出视频」在本机生成带混音的 MP4，也可单独下载 SRT。

不提供 AI、自动识别字幕、自动删停顿、私人动效生成或 PRO版后台。没有 API 配置，不调用远程 AI，不上传视频。PRO版入口只介绍产品，由用户主动打开。

编辑器中的「灵思 PRO」会展示从对标研究、账号追踪、AI 自生长、选题脚本到自动剪辑的完整流程，并单独介绍自动剪辑中的「AI 智能匹配」与「AI 动效」。用户可直接进入灵思官网，也可扫码或复制微信号领取 PRO版试用资格；官网地址与微信号都提供复制备用入口。

## GitHub版本更新

本地启动后会自动检查 [GitHub正式版本](https://github.com/feiwu6733-arch/linsi-edit-lite/releases)。发现新版时，编辑台顶部会显示提醒；可以查看说明、稍后提醒、忽略本版本、下载并在 Windows 上更新重启。断网不影响本地剪辑，更新包会校验来源、大小、SHA-256和包内文件清单。

首次安装请从 Releases 下载 ZIP，解压后双击“启动灵思剪辑.cmd”。更新过程中保留浏览器里的本地工程；清理 `127.0.0.1:5031` 的浏览器网站数据前，仍应先下载工程包或导出成片。维护方法见 [GitHub发布与本地更新](RELEASE.md)。

工程存在当前浏览器、当前网址的 IndexedDB 中。改变端口/浏览器不会自动迁移工程；清理网站数据会清除工程，请先导出成片或工程包。刷新前手动保存；撤销历史只在当前会话保留。预览静音只影响试听；片段静音会写入导出结果。

建议从 30 秒～3 分钟口播开始，视频上限 1GB，音乐上限 250MB，工程上限 60 分钟、2000 条字幕、200 个动效、100 个图文图层。带音乐或变速混音的单次导出暂支持 20 分钟以内。输出为 H.264 + AAC MP4、30fps；编码或声音无法解码时会停止并提示。

## 动效预览与参数

点击素材卡片下方「预览动效」可打开大图，暂停、重播或拖动进度；无需先导入视频。右侧「动画与节奏」支持 4 档节奏、4 种入场、4 种退场，以及过渡时长和透明度。动画参数会随工程保存，并应用于成片导出。

较短片段会自动压缩动画过渡，先完成内容呈现，再退场。经典章节导航保持真实视频时间，可增删 2～12 个章节，单独调整名称、起点及颜色。右侧「预览」只播放选中的片段，结束后自动暂停。

已保存的旧工程保持原动画；选择片段后调整动画参数，或点击「恢复默认动画」，即可使用新的动画控制。

## 人物演示与换片

内置商业版人物演示的体验分支：10 秒 1920×1080 静态无声剪影，4 条手动字幕、6 段可编辑动效及经典章节导航。动画由独立字幕和卡片绘制，底片不讲话。每次打开生成新副本，不覆盖已保存工程。

「保留排版换视频」创建一个新工程，保留文字与动效的原时间。短视频会截短或移除超出时长的片段，长视频不会自动补充后续字幕；换片后需核对文案和时间。

证据媒体墙需要上传 3 张图片后才能导出。支持 JPG、PNG、WebP，单张最大 10 MB，导入时缩至最长边 1200 像素；工程最多 60 张图片。双指标与趋势的数值由用户填写，内置数值只是演示。

## 开发

所有依赖独立安装，不引用其他本地项目。

```sh
npm ci
npm test
npm run build
python serve.py --no-browser
```

开发预览：`npm run dev`。如 5031 被占用，使用 `python serve.py --port 5032`，不会停止其他服务。发布包包含源码、锁定依赖清单、构建产物与许可，不包含 node_modules、运行日志或测试资料。`python scripts/package.py` 生成独立发行包。
