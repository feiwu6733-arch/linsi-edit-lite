# 版本发布与更新

本地服务启动后读取 GitHub 正式 Release。有新版本时显示更新横幅；用户可以稍后提醒、忽略本版本、下载并安装。

客户端只接受 `feiwu6733-arch/linsi-edit-lite` 的 HTTPS Release 地址、有效 SHA-256、`update_format=1` 的 MANIFEST 和发行文件清单。下载失败、摘要不一致、路径越界或包内文件不一致时不会安装。

Windows 安装时先等待当前服务退出，再备份将替换的发行文件并安装新版本。随后重新启动本地服务并检查 `/api/health`；新版本未能启动时恢复旧文件并重新打开原版本。

浏览器工程存放在 `127.0.0.1:5031` 对应的本地浏览器存储中，不进入更新包。更新不会上传或删除用户的视频、音乐和工程。
